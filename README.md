# نظام غياب الطلاب
موقع عربي متجاوب لإدارة الطلاب وتسجيل الحضور والغياب حسب التاريخ، مع قاعدة بيانات Supabase وتسجيل دخول.

## إعداد قاعدة البيانات
1. أنشئ مشروعًا في https://supabase.com/
2. افتح SQL Editor ثم New query.
3. انسخ ملف `supabase-schema.sql` وشغّله بزر Run.
4. من Project Settings > API انسخ Project URL والمفتاح العام anon/public أو publishable.

## ربط الموقع
افتح `app.js` وغيّر `YOUR_SUPABASE_URL` و`YOUR_SUPABASE_ANON_KEY` إلى القيم التي نسختها. لا تستخدم أبدًا مفتاح service_role داخل ملفات الموقع.

## النشر
1. افتح https://vercel.com/ وسجّل الدخول باستخدام GitHub.
2. اختر Add New > Project ثم استورد مستودع `mootazyasser34-jpg/university-attendance.`.
3. لموقع HTML عادي اترك إعدادات البناء الافتراضية واضغط Deploy.
4. استخدم رابط vercel.app الذي سيظهر بعد نجاح النشر.

## تنبيه خصوصية
سياسات قاعدة البيانات الحالية تسمح لكل مستخدم مسجل في مشروع Supabase نفسه برؤية وتعديل بيانات الطلاب. استخدم بيانات تجريبية إلى أن تُضبط صلاحيات المستخدمين حسب احتياج المؤسسة، ولا ترفع بيانات شخصية أو حساسة حقيقية قبل مراجعة الصلاحيات.
